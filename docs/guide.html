Windows voice assistant

Hard2Assist

It sits in the corner listening. You say “computer” and then what you want, and it opens things, moves windows around, types for you, and answers questions about the PC out loud. That’s the whole idea — there is nothing to click.

The only rule

Start every command with the wake word.

computer open notepad

Without “computer” in front, it ignores you completely — that’s what stops it firing every time somebody says “close the door” in the room. Everything on this page assumes you said it first.

You can change the word to anything you like. Say computer customize and it will ask you. Pick jarvis and from then on it answers to “jarvis open notepad”, and to nothing else.

Try these first

Six things to say right now.

If you only remember a handful, make it these. Each one is spoken back to you, so you always hear what it decided to do.

computer open notepad

Opens it. Works for any program, folder or website it knows.

computer what time is it

Says it out loud — “It’s 8:02 pm.”

computer type hello there

Types it into whatever window is in front.

computer close it

Closes the last thing you named. No need to say “notepad” twice.

computer turn up the volume

Louder. Talking in a normal sentence is fine.

computer help

Prints everything it knows into its own window.

Opening things

Programs, folders and websites all work the same way.

There is one open command, not three. Whether the thing is an app, a folder on the disk or a site on the internet makes no difference to what you say.

computer open calculator

Anything built into Windows — paint, settings, task manager, command prompt.

computer open obs studio

Anything in the Start Menu. Nothing to set up — it reads the list at launch.

computer open youtube

Opens the site in your browser. Also google, gmail, reddit, github, twitch.

computer open downloads

Opens the folder. Also documents, desktop, pictures, music, videos, home.

computer search how to cook rice

Puts the results in your browser.

On this PC that adds up to 131 things it can open without any setup at all: 25 built into Windows, 87 found in the Start Menu, 12 websites and 7 folders.

Moving windows around

Everything you’d normally do with the mouse.

computer focus notepad

Brings it to the front, even if it was minimised.

computer minimize notepad

Sends it to the taskbar.

computer fullscreen notepad

Fills the screen. Saying “full screen” as two words works too.

computer shrink notepad

Back to normal size. “Exit fullscreen” does the same.

computer close notepad

Closes it politely — it can still prompt you to save.

computer close all notepad

Every window of it, not just the one you opened last.

computer kill notepad

Forces it to stop, for when it has hung. Nothing gets saved.

computer what’s open

Lists the windows currently on screen.

Plain close is the careful one. Say close cmd with three terminals open and it closes the one you opened most recently — so closing something by voice never takes down the window you were actually working in.

Typing for you

It has a keyboard as well as a mouse.

Text goes into whichever window is in front. If Hard2Assist’s own window happens to be in front, it switches to the app you last named first — so “open notepad” then “type something” does what it sounds like.

computer type hello there

Types it. The first letter is capitalised for you.

computer type hello comma how are you question mark

Types “Hello, how are you?” — punctuation has to be spoken.

computer press enter

One key, or a shortcut.

computer dictate

Types everything you say from then on, until you say computer stop dictating.

Punctuation you can say

comma period question mark exclamation mark new line new paragraph

Speech recognition hands over bare lowercase words with no punctuation at all, so these are the way to get any in. The trade is that you can’t type the word “period” literally any more.

Keys you can press

enter tab escape space backspace delete up down left right home end save copy paste cut undo redo select all find print new tab

The last ones are shortcuts — press save is Ctrl+S, press paste is Ctrl+V.

Dictation drops the wake word. It has to — nobody can say “computer” before every sentence of a paragraph. While it runs, everything you say gets typed — which is why the wake word comes back for the one sentence that ends it. Say computer stop dictating when you’re done, even on the end of your last sentence; the sentence is typed and dictation stops. A bare stop is not enough on purpose, because it ends ordinary sentences too. If you go quiet for a while it stops by itself.

Telling you things

Questions it answers out loud.

computer time

“It’s 8:02 pm.”

computer date

“It’s Friday, August 8.”

computer battery

“82 percent, charging.”

computer status

“CPU 12 percent, memory 46 percent.”

computer disk

“C has 58 gigabytes free.”

Controlling it

The volume, the voice, and the off switch.

computer volume up

Also down, and mute.

computer volume 50

Exactly half. Saying “fifty” works as well as the number.

computer quiet

Stops it talking back. It still does what you ask, silently.

computer speak

Voice back on.

computer customize

Change the wake word, and when it listens.

computer stop

Quits. “Goodbye” and “see you later” work too.

Worth knowing

Four things that stop it feeling like a robot.

It expects to be misheard

Speech recognition hears “clothes” when you say “close” nearly every single time. Rather than fail, every command carries a list of what it actually gets misheard as — and it tells you when it corrects one.

clothes notepad → close notepad

You can talk in sentences

The command word can sit anywhere in what you say, so you don’t have to speak like a robot to be understood. All four of these work exactly as well as the short version.

computer what time is it

computer can you open notepad

computer turn up the volume

computer how much battery is left

“It” means the last thing you named

Name something once and then just say it, that or this until you name something else. Say what’s open if you lose track.

computer open notepad

computer type hello there

computer minimize it

computer close it

If it doesn’t know something, it asks once

Ask for a program it can’t find and a file picker opens. Click the program once and it is remembered permanently — you’re never asked again. It doesn’t ask you to read out C:\Program Files\…, because nobody can.

The first run

It sets itself up by talking to you.

The very first time it starts, it asks two questions out loud, explains each one, reads your answer back and waits for you to confirm before saving. Say keep to leave any answer alone. If it mishears three times it keeps the current setting, says so, and moves on — a bad microphone costs you a setting, never the whole app.

What should it answer to?

Any single word of three letters or more. “Computer” out of the box.

When should it listen?

Always is properly hands-free, but the microphone is live the whole time the app is running. Only when in focus means it ignores everything until you click its window — more private, but you have to click first.

Limits

What it can’t do, so you’re not surprised.

It needs the internet to hear you.

Listening goes to Google’s free speech service, so with the Wi-Fi off it can’t understand anything. The voice that answers you is Windows’ own and never leaves the PC — it’s only the listening that needs a connection.

Programs running as administrator are off limits.

Task Manager, Registry Editor and friends. Windows won’t let an ordinary program touch them, so close, type and press say they were refused rather than pretending it worked. Starting Hard2Assist as administrator lifts that.

Windows sometimes refuses to bring a window forward.

There are cases where it won’t let a background program steal the foreground. When that happens focus tells you, and the taskbar button flashes instead.

Closing Start Menu programs is best-effort.

They’re matched by their window title, which doesn’t always match the name on the shortcut. Opening them always works; closing them usually does. Anything you pointed it at yourself closes reliably.

Two things are needed to run it: a microphone and an internet connection. It installs from a single setup file and brings its own copy of Python, so there’s nothing else to install. When you’re done, say computer stop.
